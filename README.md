# Speed-Detection-# Vehicle Velocity Analytics Pipeline

An automated, full-stack computer vision pipeline designed to perform real-time vehicle tracking, perspective transformation, and velocity inference on traffic footage. 

This project bridges a modern Next.js frontend with a heavy deep-learning Python backend. It is explicitly engineered to bypass the strict compute and timeout limits of standard serverless architecture by utilizing a dedicated AWS EC2 deployment, secure TCP tunneling, and raw data encoding.

---

## 🚀 Tech Stack

**Frontend**
* Next.js (React)
* Tailwind CSS
* Hosted on Vercel

**Backend & Deep Learning**
* FastAPI (Python, Uvicorn)
* Ultralytics YOLOv8 (Object Detection)
* OpenCV (Perspective Transformation & Frame Processing)
* PyTorch (CPU Inference)

**Infrastructure & Networking**
* AWS EC2 (Ubuntu `t2.micro` Free-Tier)
* Ngrok (Secure TCP/HTTP Tunneling)

---

## 🧠 System Architecture & Data Flow

Standard serverless platforms (like Vercel Serverless Functions or AWS Lambda) strictly kill processes after 10–60 seconds, which crashes long-running video inference tasks. To solve this, the processing engine was decoupled and deployed to a dedicated AWS EC2 instance.

1. **Client Upload:** The user uploads traffic footage via the Next.js client and calibrates a specific Region of Interest (ROI) polygon.
2. **Secure Routing:** An Ngrok secure tunnel bypasses standard reverse-proxy timeouts, routing the multipart form data directly into the isolated AWS environment.
3. **AI Inference:** FastAPI receives the payload and triggers the YOLOv8 tracking pipeline. OpenCV calculates the perspective warp to translate pixel movement into real-world kilometers per hour.
4. **Base64 Payload Encoding:** Ngrok's free tier natively blocks cross-origin cookies and intercepts `.mp4` file requests with a static HTML security warning, breaking frontend video players. To bypass this CORS restriction and file interception, the backend converts the processed video directly into a raw Base64 string.
5. **Seamless Delivery:** The encoded video string is injected into the final JSON response, securely bypassing all network blocks and rendering instantly in the Next.js `<video>` player.

## 🛠️ Recruiter Demo & Deployment Guide

Because this architecture runs on free-tier infrastructure, the active Ngrok URL rotates and the EC2 instance is kept offline when not in use to conserve compute credits. 

Follow these steps to spin up the full pipeline from a cold start for a live demonstration:

### 1. Initialize the AWS Server
1. Log into the AWS Console and start the target **EC2 Instance**.
2. SSH into the Ubuntu instance from your local terminal.

### 2. Establish the Secure Tunnel
Run Ngrok on port 8000 to expose the local backend to the public web safely:
```bash
ngrok http 8000
```
*Copy the forwarding URL generated by Ngrok (e.g., `https://baffle-swoosh.ngrok-free.dev`).*

### 3. Boot the FastAPI Backend
Open a second SSH terminal window into the EC2 instance and start the Python processing server:
```bash
# Navigate to the working directory
cd ~/Speed-Detection-

# Activate the virtual environment
source venv/bin/activate

# Aggressively kill any frozen zombie processes holding the port
pkill -f uvicorn

# Boot the server in the background and pipe output to logs
nohup python -m uvicorn main:app --host 0.0.0.0 --port 8000 > app.log 2>&1 &
```
*(Optional: Run `tail -f app.log` to watch the real-time YOLOv8 inference progress).*

### 4. Connect and Deploy the Frontend
1. Open the Next.js project locally.
2. Update the API fetch link (or `.env.local` variable) to match the newly generated Ngrok URL.
3. Push the changes to GitHub/Vercel or run locally via `npm run dev`. 
4. The video estimation platform is now live and fully functional.

## 📈 Future Scalability
* **GPU Acceleration:** Migrate from PyTorch CPU to a CUDA-enabled GPU instance for real-time live-stream processing instead of asynchronous batch processing.
* **SSL Certificates:** Replace the Ngrok tunnel with a static IP and Let's Encrypt SSL certificate attached directly to the AWS load balancer for permanent uptime.
